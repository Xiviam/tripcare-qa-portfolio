# API и роли

Swagger UI доступен по адресу /docs после запуска API.

## Роли

| Роль | Возможности |
|---|---|
| customer | Поиск и управление своими бронированиями, багажом, возвратами и обращениями |
| support_agent | Просмотр обращений, журнала аудита и данных бронирований |
| admin | Управление пользователями, доступ к журналу аудита и всем операциям агента |

## Endpoints

| Метод | Путь | Назначение |
|---|---|---|
| GET | /health | Проверка доступности API и БД |
| POST | /auth/login | Получение JWT |
| GET | /auth/me | Данные текущего пользователя |
| GET | /bookings/search | Поиск бронирования по PNR и фамилии |
| GET | /bookings/{id} | Детали бронирования |
| PATCH | /bookings/{id}/contacts | Изменение email и телефона |
| POST | /bookings/{id}/baggage | Добавление багажа и расчет стоимости |
| POST | /bookings/{id}/refunds | Создание запроса на возврат |
| GET | /knowledge-base | Поиск статей базы знаний |
| POST | /support/tickets | Создание обращения |
| GET | /support/tickets | История обращений |
| GET | /admin/users | Список пользователей для admin |
| GET | /audit-log | Журнал аудита для support/admin |

## HTTP-коды

- 200 - успешное чтение или изменение.
- 201 - создание багажа, возврата или обращения.
- 401 - отсутствует или невалиден JWT.
- 403 - роль не имеет доступа.
- 404 - сущность не найдена.
- 409 - конфликт состояния, например повторный возврат.
- 422 - ошибка валидации.
